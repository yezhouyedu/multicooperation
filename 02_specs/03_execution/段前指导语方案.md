# 段前指导语方案

更新时间：2026-09-06

## 1. 当前口径

正式实验在三个正式工作段前增加“阅读材料”页：

- 测试轮完成、双方 formal ready 后，进入段 1 前指导语。
- 工作段 1 后常规问卷提交并完成休息后，进入段 2 前指导语。
- 工作段 2 后常规问卷提交并完成休息后，进入段 3 前指导语。
- 工作段 3 后仍按既有问卷流程：段 3 常规问卷 → 最终长问卷 → 实验结束。

段前指导语不计入正式工作段时间，不计入 A 单家公司 5 分钟窗口，也不计入 B PreA 空窗。

## 2. 页面规则

前台页面标题统一显示为“阅读材料”，不显示 `neutral_1`、`coop_narrative`、处理组、控制组等后台名称。

页面打开后 15 秒内继续按钮禁用并显示倒计时；15 秒后按钮变为可点击。单方点击继续后停留在等待状态，双方都完成后才进入对应正式工作段。

后端会校验：

- 当前 session 必须处于 `PRE_SEGMENT_INSTRUCTION`。
- participant 必须属于当前 session。
- participant 必须先记录打开事件。
- 从打开到完成至少经过 15 秒。

## 3. 文本与类型

文本来源为：

`00_start_materials/第十次开会/段前指导语文本与第三章叙事随机机制说明_V0.4.md`

正式文本使用 V0.4 第 4 节的六段冻结候选文本，文本 ID 均升级为 `_V2`。六段文本保持技术中性，不出现 AI、大模型、提醒制度或要求参与者采取特定合作行为的表述。

实现层记录精确文本类型：

- `neutral_1`
- `neutral_2`
- `neutral_3`
- `complementarity`
- `verification_trace`
- `shared_responsibility`

导出摘要额外归并：

- `instructionFamily = neutral`
- `instructionFamily = coop`

## 4. 当前随机机制

新正式 session 使用 A0-A8 条件，不再根据旧实验 1/2/3 模式生成指导语计划；合作叙事组为 A4/A5/A8：

- A0、A1、A2、A3、A6、A7 的 `narrativeGroup = neutral_info`。每队从 N1/N2/N3 的六种排列中随机抽取一种，三个工作段各出现一次且不重复；不再固定为 `N1 → N2 → N3`。
- A4、A5、A8 的 `narrativeGroup = coop_narrative`。每队从 C/V/S 的六种排列中随机抽取一种，且每段指导语主题与当段任务2合作主题一致。
- `manual` 调试模式当前仍固定展示 `neutral_1 → neutral_2 → neutral_3`。
- 旧 `coop_narrative` session 若快照中已经保存随机中性顺序，继续按历史快照读取，不迁移、不重算。

中性顺序随机是 V0.4 新增的正式约束，目的在于避免 N1/N2/N3 的文本差异始终绑定第一、第二、第三段的熟练、疲劳或位置效应。随机发生在团队 Session 初始化时，A/B 共享同一顺序；生成后写入快照，重启、Admin 修改或后续发布均不重抽。

`continuous / batch` 仍只控制提醒频率，不改变题目实际到达节奏。指导语页本身不额外改变任务2抽题组成：中性条件每段 40 条中性题；合作叙事条件每段 20 条当前合作主题题 + 20 条中性题。合作主题的 20 题按 V0.4 新增硬约束分层抽取：当前主题的 5 个 `content_subtype` 各随机 4 题，再与 20 条中性题合并洗牌。这样保留题目随机性，同时避免不同团队因 subtype 偶然偏科而接受不同浓度的处理。

## 5. 数据记录

不新增指导语专用表。当前复用：

- `Session.experimentSnapshot.instructionPlan`：团队级指导语计划。
- `TaskProgress`：
  - `pre_segment_instruction_opened`
  - `pre_segment_instruction_completed`
- `ExperimentEvent`：
  - `pre_segment_instruction_started`
  - `pre_segment_instruction_opened`
  - `pre_segment_instruction_completed`

`instructionPlan` 在 session 初始化时生成并固化，Admin 后续切换实验局不会改变旧 session。它包含：

- `version`
- `durationSeconds`
- `orderType`
- `orderValue`
- `instructionTypes`
- `instructionTextIds`
- `instructionFamilies`

正式新 Session 使用 `version = pre_segment_instruction_v2`。中性组保存 `orderType = neutral_order` 与 `instructionOrderSeed`；合作组保存 `orderType = theme_order` 与 `themeOrderSeed`。`instructionTextIds` 保存 `_V2` 精确文本版本，因此历史 V1 Session 无需迁移。
