# 实验条件与区组随机方案

> 当前状态：正式口径。本文档取代《实验123计划.md》中的实验 1/2/3 模式设计。

## 1. 模式

Admin 只保留两种新建 session 模式：

- `manual`：手动 / 通用调试模式。
- `formal`：正式实验模式，按预生成的七条件平衡区组顺序分配。

旧 `ai_upgrade`、`side_reminder`、`coop_narrative` 不再用于新 session。历史 session 的快照和导出仍需兼容读取。

## 2. 七个实验条件

| 条件 | AI 条件 | 任务2提醒 | 叙事条件 |
|---|---|---|---|
| A0 | `NONE`，前后端均无 AI | `continuous` | `neutral_info` |
| A1 | `BASIC` | `continuous` | `neutral_info` |
| A2 | `ADVANCED` | `continuous` | `neutral_info` |
| A3 | `BASIC` | `batch` | `neutral_info` |
| A4 | `BASIC` | `continuous` | `coop_narrative` |
| A5 | `ADVANCED` | `continuous` | `coop_narrative` |
| A6 | `ADVANCED` | `batch` | `neutral_info` |

AI 条件从测试轮/练习轮开始生效，并贯穿三个正式工作段。A0 的任务1和任务2均不显示 AI，服务端也拒绝 AI 请求。A3/A6只改变提醒频率，不改变任务2题目的实际到达节奏。A4/A5继续使用合作叙事主题顺序、段前材料和合作类任务2题组成。

Admin 不再提供“工作段 1/2/3 AI BASIC/ADVANCED”手动控件。正式模式只根据 session 领取的 A0-A6条件生成 `practiceAiState` 和三段 `segmentAiStates`；数据库原三段 AI 配置字段仅保留给手动调试兼容和历史 session 回退，不得覆盖正式条件快照。

## 3. 实验局与区组

- A0-A6称为“实验条件”。
- 一次正式开放和招募批次称为“实验局”，数据库实体为 `ExperimentRun`。
- 每个区组包含 A0-A6各一次，并使用区组 seed 做 Fisher-Yates 随机排列。
- 正式实验局默认预生成60个区组，共420个条件槽位。
- 两人匹配成功形成 session 后，在配对事务内领取全局位置最小的可用槽位。
- 槽位领取以数据库事务和唯一约束防重复，不以时间戳精度防重复。
- 队列耗尽时按主 seed 和新区组号确定性追加区组，不设固定被试容量上限。
- 已领取槽位不因退出、失败或取消而回收。
- 同一时间只有一个正式实验局处于分配状态。激活另一个实验局时，原实验局进入暂停状态；重新激活旧实验局后，继续领取该实验局全局位置最小的可用槽位，不重新生成序列，也不重置累计进度。
- 切换到手动 / 通用模式时，当前正式实验局同步暂停；之后仍可从 Admin 继续该实验局。
- 只有未激活且没有任何关联 `Session` 的实验局可以删除。存在关联被试数据时，服务端必须拒绝删除并提示先清理对应 Session；删除实验局会级联删除其未使用和无 Session 引用的条件槽位。
- 当前激活实验局由数据库 `ExperimentConfig.activeExperimentRunId` 唯一确定；Session 归属由 `Session.experimentRunId` 和 `Session.experimentCondition` 持久化保存，Admin 展示、筛选与导出不得依赖浏览器缓存。

## 4. 三层随机化

1. 实验条件随机：session领取区组槽位，得到 A0-A6之一。
2. 角色随机：两人组内使用独立 seed 随机分配 A/B。
3. 公司顺序随机：session使用独立 seed 生成正式公司共享顺序。

三层随机化分别保存方法、seed、时间和结果，不共用 seed。

## 5. 快照与兼容

新正式 session 保存 `experimentRunId`、`experimentCondition`、`aiEnabled`、`aiCondition`、`segmentAiStates`、`sideDispatchMode`、`narrativeGroup` 和指导语计划。Admin 后续修改不影响旧 session。

`upgradeCohort` 不再用于新正式实验。数据库旧列暂作为 legacy 保留，避免破坏历史 session；新正式 session 写 `null`，导出优先读取七条件字段。
