# 线上实验质量与行为监测方案

> 当前真相源：2026-08-23；实现版本 `online_integrity_v1`。本文覆盖正式线上实验中的全屏、切屏、无效行为、掉线、正式退出、剪贴板摘要、数据落库与导出。若其他文档冲突，以本文、`APP_FLOW.md` 和 `数据库文件夹手册.md` 为准。

## 1. 适用边界

- 只在 `RuntimePhase.FORMAL_WORK` 正式工作段启用。
- 指导语、测试题、测试轮、段前指导、休息、段后问卷、最终问卷和支付确认均不作切屏或无效行为判定。
- 普通网页不能知道被试眼睛看向哪里，也不能发现另一台手机上的 AI；本系统记录的是可审计的网页/连接行为和最终自报，不宣称等同真实注意力。
- 不录屏、不记录鼠标轨迹、不保存按键内容、不保存剪贴板原文。

## 2. 工作流总图

```text
正式工作段开始
  -> 全屏门禁（用户点击进入全屏）
  -> 浏览器监听：有效操作 / 页面隐藏与窗口失焦 / 心跳 / 复制粘贴摘要
  -> API 上报：低频心跳 + 区间开始/结束 + 少量关键事件
  -> PostgreSQL：ParticipantIntegrityState 当前汇总 + OnlineIntegrityInterval 原始区间
  -> Session/参与者质量标记
  -> 导出 participants/{participantId}/online_integrity.json
  -> 数据清洗按关键 flag 排除或分层分析
```

## 3. 全屏与切屏

### 3.1 全屏门禁

- 正式工作段首次进入、从切屏返回或退出浏览器全屏时，覆盖层阻断工作台。
- 被试必须点击“恢复全屏并继续”，该点击作为浏览器用户手势调用 Fullscreen API。
- 单纯退出全屏不落库、不判违规；如果同时导致页面隐藏或窗口失焦，则按切屏区间记录。

### 3.2 切屏定义

满足任一条件即开始同一个 `OFFSCREEN` 区间：

- `document.visibilityState === hidden`；
- 浏览器窗口失去操作系统焦点。

因此切换标签页、Alt+Tab 到微信、Win+D、最小化浏览器、切换到另一显示器上的应用均属于切屏。`visibilitychange` 与 `blur` 必须合并去重，恢复到“页面可见且窗口有焦点”时结束区间。

- 每一次区间都落库。
- `durationMs > offscreenViolationSeconds * 1000` 才令 `hasOffscreenViolation=true`；默认阈值为 2 秒，恰好 2.000 秒不判正式违规。
- 高级 AI 的图片选择窗口由 `experiment-authorized-file-dialog` 标记为授权窗口，最长默认 60 秒；授权窗口仍可审计，但不判切屏违规。

## 4. 无效行为状态机

```text
最后一次有效操作
  -> 120 秒无有效操作
  -> 弹出“仍在参与实验吗？”并记录 idle_prompt_shown
     -> 20 秒内确认：记录 idle_prompt_confirmed；重置计时；不判无效
     -> 20 秒内未确认：开启 INACTIVITY 区间；hasInvalidInactivity=true
        -> 下一次可信的键盘、输入、点击、触控或滚轮操作：关闭区间
        -> 工作段结束或正式退出：由系统关闭区间
```

有效操作只在浏览器本地更新时间，不逐次上传。鼠标悬停和原始轨迹不作为服务器数据。`hasInvalidInactivity=true` 是清洗时的关键不可用标记；软提醒本身不使数据无效。

每个无效区间至少保存：`idleCountdownStartedAt`、`promptShownAt`、`confirmationDeadlineAt`、`invalidStartedAt`、`invalidEndedAt`、`durationMs`、`endReason`、所在工作段/任务/公司。

## 5. 心跳、关闭网页与正式退出

- 正式工作段浏览器默认每 10 秒更新 `lastHeartbeatAt`；心跳只更新状态表，不生成一条事件日志。
- 超过 `connectionLostGraceSeconds`（默认 30 秒）开启 `DISCONNECT` 区间。
- 心跳恢复时关闭掉线区间；服务器阶段计时和任务计时不暂停。
- 超过 `dropoutTimeoutSeconds`（默认 180 秒）或被试点击“确认退出”，设置 `hasFormalDropout=true`。
- `beforeunload/sendBeacon` 仅作辅助；是否掉线和退出以服务器最后心跳时间为准。

状态优先级：`DROPPED > DISCONNECTED > OFFSCREEN > INACTIVITY > ACTIVE`。

### 5.1 A/B 非对称退出

| 事件 | 留在实验中的人 | 服务器行为 |
|---|---|---|
| A 正式退出 | B 停止 | B 显示“队友 A 已退出，实验结束”；B 的草稿修改、查看 A 信息和提交接口均拒绝；历史数据保留 |
| B 正式退出 | A 继续 | A 显示中性提示但不阻断；A 按原时间线完成全部剩余任务；Session 标记受 B 退出影响 |
| 暂时掉线但未到 180 秒 | 双方继续 | 记录掉线区间，重连后恢复；不提前改变协作规则 |

## 6. 剪贴板与平台外工具

- `copy/paste` 仅保存字符数、`SHA-256(sessionCode + text)` 摘要、内部/外部/未知分类，以及是否发生在切屏返回后的配置窗口内。
- 不保存文本原文。平台内复制后相同摘要的粘贴标为 `platform_internal`；其他粘贴标为 `platform_external`。
- 此分类只用于行为描述，不直接命名为作弊；手机或第二设备由最终问卷 `POST-ONLINE-01..04` 自报补充。

## 7. Admin 参数

独立 Tab“线上实验质量”管理以下字段，并在 Session 成组时冻结到 `Session.experimentSnapshot.onlineIntegrity`：

| 参数 | 默认值 | 约束 |
|---|---:|---|
| `enabled` | true | 总开关 |
| `idlePromptSeconds` | 120 | 10–3600 |
| `idleConfirmationGraceSeconds` | 20 | 5–300 |
| `heartbeatIntervalSeconds` | 10 | 2–60，且小于掉线宽限 |
| `connectionLostGraceSeconds` | 30 | 5–300，且小于正式退出阈值 |
| `dropoutTimeoutSeconds` | 180 | 30–3600 |
| `offscreenViolationSeconds` | 2 | 0–60；严格大于才违规 |
| `fullscreenRequired` | true | 全屏门禁开关 |
| `authorizedDialogMaxSeconds` | 60 | 5–600 |
| `pasteAfterOffscreenWindowSeconds` | 30 | 0–600 |

## 8. 数据落库与导出

- `ParticipantIntegrityState`：每个 Session × Participant 一行；保存当前状态、最后心跳/有效操作、关键 flags、次数、累计时长、正式退出、规则承诺和终问自报。
- `OnlineIntegrityInterval`：每个 `INACTIVITY/OFFSCREEN/DISCONNECT` 一行；保存开始、结束、时长、违规与上下文。
- `ExperimentEvent`：只保存软提醒、剪贴板摘要、承诺、退出和队友提示等离散关键事件。
- `session_metadata.json.qualityFlags`：团队派生标记，`sessionDataUsable=false` 当任一成员存在无效行为、切屏违规或正式退出。
- `participants/{id}/online_integrity.json`：配置快照、参与者质量汇总、全部区间、软提醒/剪贴板/退出事件。

完整字段定义不得只留在本文，必须同步维护于 `02_specs/04_pre_deploy/数据库文件夹手册.md`。

## 9. 验收口径

1. 普通全屏退出：出现阻断层，但数据库无 fullscreen 区间。
2. 切屏 1 秒和 2 秒：均有 `OFFSCREEN`；均不置违规。
3. 切屏 2.001 秒以上：区间存在且 `isViolation=true`，参与者 flag=true。
4. 120 秒后 20 秒内确认：仅有两条软提醒事件，无 `INACTIVITY`。
5. 20 秒未确认：立即设置关键无效 flag；下一次有效操作关闭区间。
6. 图片选择窗口：区间带 `authorizedDialog=true`，不置切屏违规。
7. 断网超过 30 秒后恢复：有 `DISCONNECT` 区间但无正式退出。
8. 超过 180 秒：正式退出；A/B 后续行为符合非对称表。
9. 最终导出 JSON 的 flags、次数、时长和原始区间可互相核算。
